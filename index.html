Make every gaming clip count.

GTA Shorts Publisher is a desktop-based workflow for preparing short-form gaming clips, suggesting titles and captions with locally running AI, and helping an authorized creator send finished videos to supported platforms.

What the application is designed to do

📁 Use finished clips

Work with MP4 videos in a folder selected by the creator. This site does not provide video hosting or a public upload portal.

✨ Suggest metadata

Generate draft titles, descriptions and hashtags using a locally running AI model. Creators remain responsible for reviewing accuracy.

📤 Connect platforms

Support authorized publishing workflows through platform APIs. TikTok integration is under development and subject to TikTok approval.

TikTok integration

The planned TikTok Content Posting API integration will let a creator authorize their account and submit selected MP4 clips for review within TikTok using the applicable upload permissions. This does not imply unrestricted automatic public posting. Features requiring approval will remain unavailable until authorization and review requirements are met.

Independent project

This is an independently developed creator tool. It is not affiliated with, endorsed by, or operated by TikTok, Meta, Google, YouTube, Rockstar Games, or the makers of the games shown in user-provided footage.
